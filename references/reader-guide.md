# Reader guide · 怎么读一份 Standard DD

> 目标读者：第一次打开 APR 类报告的人。  
> 设计取向：**机构级完整度** > 推特线程式可读性。但不应在首屏就劝退。

---

## 60 秒路径（推荐）

1. **§0 结论** — Verdict + 动作桶 + 为何是现在  
2. **TL;DR / 如何阅读** — 若有，先读这 8 行  
3. **§2.5–2.6** — 供应/竞品（数字锚）  
4. **§3** — 场所、OI、funding、链上 proxy  
5. **§7a / §7b** — 投资 thesis **与** 投机 thesis（两段，不可混）  
6. **溯源表** — 需要质疑某个数字时再展开  

**不必线性读完。** Watch-only 报告的价值在「可证伪清单」，不在喊单。

---

## 三类读者预期

| 读者 | 预期体验 | 若觉得难读 |
|------|----------|------------|
| **交易者** | 3 分钟拿到 verdict + 失效条件 + 拥挤度 | 直接跳 §0、§3、监控清单 |
| **Skill 评估者** | 看 template 是否落地（溯源表、三态支柱） | 对照 `report-template.md` 逐节勾 |
| **普通读者** | 可能偏难 — 需 TL;DR | 没有 TL;DR 的报告 = 模板未达标 |

---

## 公开稿硬性排版（v2.1+）

- Metadata 之后 **≤400 字内** 必须有：**TL;DR + Verdict + 一张关键图或表**  
- **溯源表默认后置**（HTML 版可折叠 `<details>`）  
- 首屏禁止只有元数据墙 + 空表格
